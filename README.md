# Employee Management App

A frontend Employee Management App built using React, JavaScript, and Bootstrap.

## Features

- Add new employees
- Edit and update employee details
- Delete employees
- Search employees by name
- Filter employees by role
- Form validation for empty inputs
- Responsive employee table

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Bootstrap
- Vite

## Getting Started

1. Clone this repository.
2. Open the project folder in VS Code.
3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

5. Open the local URL shown in the terminal.

## Production Build

To create a production build, run:

`npm run build`
